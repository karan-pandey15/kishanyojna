# Bhartiya Kisan Union (Umakanth)

Official foundation website built with **Next.js 16** and **Tailwind CSS v4**.

## Motives of work

1. Child Welfare  
2. Child Education  
3. Child Health  
4. Children Sports  
5. Farmers Social Rights  
6. Old Age People Welfare  

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Key pages for bank / CERT audit

- `/compliance` — organisation identity, office address, leadership, objects, bank placeholders  
- `/donate` — donation instructions  
- `/about` — who we are  
- `/contact` — central office contacts  
- `/privacy` & `/terms` — required policy pages  

## Images

Place assets in `public/images/` (already included: `one.jpeg` … `five.jpeg`, `homepagelaptopscreen.jpeg`, `letterhead.png`).

After the bank account is approved, update account fields in `app/compliance/page.tsx` and `app/donate/page.tsx`.
